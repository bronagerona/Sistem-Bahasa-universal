## Commit A — Penanganan assertion

LanguageGenerator menangani `reasoning_type="assertion"` dengan acknowledgment alami sesuai register. Pernyataan literal tidak diubah menjadi kesimpulan faktual yang tidak didukung.

Contoh: input **“Api menyentuh rumah kayu”** dikenali sebagai pernyataan. ILIS mengakui pernyataan tersebut dan TIDAK menyimpulkan bahwa rumah terbakar.

## Commit B — Awalan identitas hanya untuk Identity Intent

Awalan identitas Mode A **“Saya ILIS, sistem kecerdasan bahasa.”** kini hanya muncul ketika Identity Intent terpicu, misalnya saat pengguna bertanya **“Siapa kamu?”**.

Untuk sapaan, pertanyaan biasa, perintah, dan assertion, jawaban Mode A tidak lagi menampilkan awalan identitas tersebut. Identitas aplikasi Mode B dan identitas karakter/NPC Mode C tetap dipertahankan.

Perubahan produksi Commit B terbatas pada `PersonaRenderer` dan `ChatbotAdapter`. Commit A tidak diubah.

## Expected Failure pada CI — Catatan untuk reviewer

**Expected Failure:** `tests/beta_suite.py::test_beta_chatbot_full_pipeline_and_register`

**Alasan:** Perubahan perilaku yang disengaja. Pernyataan **“Api menyentuh rumah kayu”** hanya diakui sebagai pernyataan, TIDAK disimpulkan sebagai kebakaran. Tes beta lama masih menunggu jawaban **“Ada kemungkinan…”**.

Ini **BUKAN bug kode**. Penyesuaian ekspektasi tes beta suite harus ditinjau pada tahap mendatang, ketika revisi beta suite telah dijadwalkan dan disetujui. Sampai saat itu, biarkan tes ini tetap berstatus expected failure. **Jangan mengubah atau menghapus tes tersebut sebagai bagian dari Commit A atau Commit B.**

Isi `tests/beta_suite.py` tidak diubah. Konfigurasi CI menandai hanya node tes tersebut sebagai `xfail` non-strict. Tes tetap dikumpulkan dan dijalankan; bukan di-skip atau dihapus. Jika tes tiba-tiba lulus, pytest melaporkannya sebagai `XPASS` agar perubahan tak terduga terlihat.
