Status: pengembangan / PR #16 belum di-merge.

## Commit A — Penanganan assertion

LanguageGenerator kini menangani `reasoning_type="assertion"` dengan acknowledgment alami sesuai register. Pernyataan literal tidak diubah menjadi kesimpulan faktual yang tidak didukung.

Contoh: input **“Api menyentuh rumah kayu”** dikenali sebagai pernyataan. ILIS mengakui pernyataan tersebut dan TIDAK menyimpulkan bahwa rumah terbakar.

## Expected Failure pada CI

**Expected Failure:** `tests/beta_suite.py::test_beta_chatbot_full_pipeline_and_register`

**Alasan:** Perubahan perilaku yang disengaja. Pernyataan **“Api menyentuh rumah kayu”** hanya diakui sebagai pernyataan, TIDAK disimpulkan sebagai kebakaran. Tes beta lama masih menunggu jawaban **“Ada kemungkinan…”**.

Ini **BUKAN bug kode**. Penyesuaian ekspektasi tes beta suite dijadwalkan untuk tahap mendatang. Isi `tests/beta_suite.py` tidak diubah.

Konfigurasi CI menandai hanya node tes tersebut sebagai `xfail` non-strict. Tes tetap dikumpulkan dan dijalankan; bukan di-skip atau dihapus. Jika tes tiba-tiba lulus, pytest melaporkannya sebagai `XPASS` agar perubahan tak terduga terlihat.

Target hasil CI: **307 passed + 1 xfailed**. Semua tes lainnya tetap wajib lulus.
